Notas de versión · v1.2.4

  • Añadido botón “Borrar datos” para vaciar campos, limpiar la ruta y dejar la app lista para otro trayecto.
  • Mejorado el reseteo completo: ahora también limpia ruta estimada, líneas del mapa y estados internos.
  • Añadida respuesta visual al pulsar botones para que se note mejor cada acción.
  • Corregidos pequeños fallos de estado al pausar, reiniciar o preparar una nueva ruta.
  • Pulido general de estabilidad y experiencia móvil.

Ayuda

  • Usa “Ubicación actual” para rellenar el origen automáticamente.
  • Calcula la ruta antes de iniciar para obtener una estimación más útil.
  • Amplía el mapa para ver un modo inmersivo más limpio.
  • Mientras el coche esté parado, la app evita sumar gasto irreal.

Privacidad

Los datos del trayecto se procesan en tu navegador. La app usa servicios externos de mapas y geocodificación para calcular rutas y nombres de calles.
